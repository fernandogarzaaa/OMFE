# OFM Engine

Tools for OnlyFans management agencies: creator-recruitment funnel, lead scoring, GoHighLevel
CRM sync, Meta CAPI / TikTok Events attribution, tracking links, revenue KPIs and a live dashboard.
Every integration runs in **mock mode** by default — no paid services are needed to run it.

See `docs/api-contract.md` for the REST API and `docs/backend.md` for operations.

# Follow-up sequences

SFW, compliance-first follow-up templates for creator applicants. Load them into GoHighLevel
workflows (or n8n/Make). Placeholders use GHL merge-field style: `{{contact.first_name}}`,
`{{custom_values.booking_link}}`, `{{location.name}}`.

Rules baked in: applicants are 18+ and consented on the funnel; every SMS carries opt-out text;
no explicit content; never message *as* a creator.
